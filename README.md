# GUTTER CAT

A 16-bit style survival horror RPG for the browser. You are a stray cat trying to
cross a dark, drowned city to reach a house with a yellow window, a warm bed and a
bowl of food.

Everything is generated by code when the game starts: the pixel art, the font and
all sound and music. There are no image or audio files to download.

## Run it

You need [Node.js](https://nodejs.org) 20 or newer. On Windows you can install it with:

```
winget install OpenJS.NodeJS.LTS
```

Then, from this folder:

```
npm install
npm run dev
```

The game opens in your browser (normally at http://localhost:5173).

| Command | What it does |
| --- | --- |
| `npm run dev` | Development server with live reload |
| `npm run build` | Builds one self-contained file, `dist/index.html` |
| `npm run preview` | Serves the production build |
| `npm test` | Runs the rules, map and balance tests |

`dist/index.html` needs no server: double-click it, or copy that one file anywhere.

## How it plays

- **Explore** three connected regions: The Gutter, The Abandoned District (with the
  meat plant and the Catcher's yard) and The Sewers (with the Cistern), then Marrow Lane.
- **Survive.** Hunger falls as you walk. Above 50 your wounds slowly close; below 25
  your attack weakens; at 0 you start to starve.
- **Stay hidden.** Enemies you can see will hunt you, and you can lose them by breaking
  line of sight. Trash and dead grass rustle, and things live in them.
- **Fight** in turn-based battles: Attack, Defend, Item, Escape. Enemies announce their
  big moves with a red warning before you choose. Defending takes less than half damage
  and makes your next strike 40% stronger, so reading the telegraph is the whole game.
- **Grow.** Each level raises your stats automatically and lets you choose one instinct:
  Claws, Hide, Reflex or Nine Lives.
- **Rest and save** at dry cardboard boxes. Resting heals you fully but costs food. The
  game also autosaves when you change areas and after major events.

There are three bosses, each with its own mechanic:

- **Grease** grows stronger for every rat of his still alive, and calls more.
- **The Catcher** throws a net that costs you a turn. Brace at the right moment and you
  slip it, leaving him wide open. Hurt him enough and he whistles for his dog.
- **Mother Gnaw** births brood and eats them to heal, so kill them first. At half health
  the chamber starts flooding on a countdown, and you have to brace for each surge.

## Project layout

```
src/
  main.js            Game setup, scaling, key handling
  config.js          Shared constants
  core/              State and rules, saving, audio engine, input
  data/              Items, enemies, quests, story scripts, maps (plain data)
  world/mapdata.js   Turns map definitions into playable grids
  systems/           Combat rules, dithered lighting, weather
  art/               Procedural art: pixel buffer, font, tiles, sprites, scenery
  scenes/            Boot, Title, World, UI, Battle, Menu, GameOver, Ending
  ui/widgets.js      Retro window, text and gauge helpers
tests/               Rules, map validation and balance simulation
```

Combat rules live in `systems/combat.js` with no Phaser in them. A `Battle` takes commands
and returns a list of events, which `BattleScene` plays back as animation. That is what lets
`npm test` simulate thousands of fights to check difficulty.

## Changing things

- **Balance:** `src/data/enemies.js` and `src/data/items.js`. Then run `npm test`, which prints
  win rates and fails if a fight drifts out of its intended range.
- **Maps:** `src/data/maps.js`. Rooms are carved with `rect()` and props placed with `at()`. The
  tests check that everything can be reached and that story gates cannot be walked around.
- **Story:** `src/data/scripts.js`. Events are plain async functions:
  `await c.say('NAME', 'face', 'text')`, `await c.choose(...)`, `await c.battle([...])`.
